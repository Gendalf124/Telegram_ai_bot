Telegram AI Bot

Telegram-бот, разработанный на языке **Python** с использованием библиотеки **Aiogram**, предназначенный для общения с нейросетью через библиотеку **g4f (GPT4Free)**. Бот поддерживает регистрацию пользователей, ведение истории сообщений и режим непрерывного диалога с сохранением контекста общения.

## 📖 О проекте

Данный проект представляет собой интеллектуального Telegram-бота, предоставляющего пользователям возможность взаимодействия с языковой моделью через удобный интерфейс мессенджера Telegram.

Перед началом работы пользователь проходит простую процедуру регистрации, после чего получает доступ к функциям бота. История сообщений сохраняется в локальной базе данных, что позволяет поддерживать контекст диалога и обеспечивать более естественное общение.

Приложение позволяет:

* регистрировать новых пользователей;
* хранить информацию о пользователях в базе данных SQLite;
* вести диалог с нейросетью;
* поддерживать режим непрерывного общения с сохранением контекста;
* отправлять быстрые запросы без сохранения истории;
* автоматически очищать историю сообщений после завершения диалога.

Проект демонстрирует использование современных технологий разработки Telegram-ботов и интеграции с языковыми моделями искусственного интеллекта.

# 📦 Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Gendalf124/Telegram_ai_bot.git
```

2. Перейдите в папку проекта:

```bash
cd Telegram_ai_bot
```

3. Установите необходимые библиотеки:

```bash
pip install aiogram g4f
```

4. Укажите токен вашего Telegram-бота, полученный через **@BotFather**, в основном файле проекта.

---

# ▶️ Запуск приложения

Запустите бота командой:

```bash
python бот.py
```

После запуска бот начнет принимать сообщения в Telegram.

# 📊 Возможности приложения

### 🤖 Общение с нейросетью

Поддержка взаимодействия с языковой моделью через библиотеку **g4f**, позволяющей получать ответы на текстовые запросы пользователей.

---

### 👤 Регистрация пользователей

Перед использованием бота пользователь проходит регистрацию, после чего информация сохраняется в локальной базе данных.

---

### 💬 История сообщений

Система сохраняет историю переписки и поддерживает режим непрерывного диалога с учетом предыдущих сообщений.

---

### ⚡ Быстрые запросы

Пользователь может отправлять отдельные запросы без сохранения контекста предыдущего общения.
